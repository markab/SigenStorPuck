SigenStorPuck

A round status display for a SigenStor solar and battery installation.

This browser cannot flash over USB. Open this page in Chrome or Edge on a desktop — WebSerial does not exist in Safari or Firefox, and is unavailable on iOS entirely. Serial access was blocked. This page has to be served over HTTPS to flash.

After flashing

  1. The Puck raises a WiFi access point called SigenStorPuck-Setup. Join it and choose your network.
  2. Open http://sigenstorpuck.local/ and paste the enrolment URL from SigenStor Display's Admin → Kiosk devices.
  3. It starts showing live data, and updates itself from GitHub Releases after that.
Only needed once. This installer is for the first flash and for recovery. Afterwards the Puck updates itself, so you should not need to come back here.

Hardware

Waveshare ESP32-S3-Touch-AMOLED-1.75 — a 466×466 round AMOLED with capacitive touch. Plug it into this computer with USB-C before clicking Install.
