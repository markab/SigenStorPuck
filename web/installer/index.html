SigenStorPuck

A status display for a SigenStor solar and battery installation.

After flashing

  1. The Puck raises a WiFi access point called SigenStorPuck-Setup. Join it and choose your network.
  2. Open http://sigenstorpuck.local/ and choose your data source: talk straight to the plant over Modbus (the default), use Home Assistant, or a SigenStorDisplay Server. Only the server needs an enrolment URL — Modbus needs the plant's IP, Home Assistant its URL and token.
  3. It starts showing live data, and updates itself from GitHub Releases after that.
Only needed once. This installer is for the first flash and for recovery. Afterwards the Puck updates itself — and each board updates from its own build — so you should not need to come back here.
